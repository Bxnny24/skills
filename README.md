# Skills

Agent skills I use in my own projects, shared for anyone who finds them useful. They work with Claude Code, Codex, Cursor and other agents that read `SKILL.md` files.

## Install

```bash
npx skills add Bxnny24/skills
```

Pick a single skill with `--skill <name>`, update later with `npx skills update`.

## Skills

| Skill | What it does |
|---|---|
| [interaction-audit](skills/interaction-audit/SKILL.md) | Walks through a whole app and exercises every interaction (buttons, menus, gestures, settings, accessibility features, offline and empty states) on iOS, Android, web, browser extensions or desktop, checks layout against the app's design language, covers plans, roles and feature flags, OS versions and browsers, store and legal readiness, and produces a clickable report that compares screenshots with the previous run. |
